# Basics - Scripts Shell

Ce dossier contient les scripts d'introduction aux commandes de base du shell :

* `0-current_working_directory` : Affiche le chemin absolu du répertoire de travail actuel.
* `1-listit` : Affiche la liste des fichiers et dossiers du répertoire courant.
* `2-bring_me_home` : Change le répertoire de travail vers le dossier personnel de l'utilisateur.
* `3-listfiles` : Affiche le contenu du répertoire courant au format long.
* `4-listmorefiles` : Affiche le contenu du répertoire courant au format long, y compris les fichiers cachés.
* `5-listfilesdigitonly` : Affiche le contenu du répertoire au format long avec les identifiants numériques (UID/GID) et les fichiers cachés.
* `6-firstdirectory` : Crée un répertoire nommé `my_first_directory` dans le dossier `/tmp/`.
* `7-movethatfile` : Déplace le fichier `betty` depuis `/tmp/` vers `/tmp/my_first_directory/`.
* `8-firstdelete` : Supprime le fichier `betty` situé dans `/tmp/my_first_directory/`.
* `9-firstdirdeletion` : Supprime le répertoire `my_first_directory` situé dans le dossier `/tmp/`.
* `10-back` : Change le répertoire de travail vers le répertoire précédent.
* `11-lists` : Affiche au format long et avec les fichiers cachés le contenu du répertoire courant, du répertoire parent et du répertoire `/boot`.
* `12-file_type` : Affiche le type du fichier `iamafile` situé dans `/tmp/`.
* `13-symbolic_link` : Crée un lien symbolique nommé `__ls__` pointant vers `/bin/ls` dans le répertoire courant.
* `14-copy_html` : Copie tous les fichiers `.html` du répertoire courant vers le répertoire parent, uniquement s'ils sont plus récents ou absents.
* `15-lets_move` : Déplace tous les fichiers commençant par une lettre majuscule vers le répertoire `/tmp/u`.
* `16-clean_emacs` : Supprime tous les fichiers du répertoire courant se terminant par le caractère `~`.
* `17-tree` : Crée un script qui crée les répertoires `welcome/`, `welcome/to/` et `welcome/to/school` dans le répertoire actuel.
